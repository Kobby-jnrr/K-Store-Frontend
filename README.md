# K-Store Frontend

The client-side interface for **K-Store**. This is a responsive web application built with **React** to help students buy and sell items on campus easily.

## 🛠 Tech Stack
- **Library:** React.js
- **Icons:** Lucide-React
- **Routing:** React Router DOM
- **HTTP Client:** Axios (or Fetch API)

## ✨ Key Features
- **Marketplace Dashboard:** Browse items by category with real-time updates.
- **User Experience:** Fully responsive design for mobile and desktop use.
- **Protected Views:** Dashboard and listing forms restricted to logged-in users.
- **Clean UI:** Intuitive interface focused on speed and simplicity.

## 🚀 Setup Instructions
1. Clone the repository:
   `git clone https://github.com/Kobby-jnrr/K-Store-Frontend.git`
2. Install dependencies:
   `npm install`
3. Start the development server:
   `npm start`
